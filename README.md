# ERAA

The Stockholm Environment Institute (SEI) is conducting an Electricity Resource Adequacy Assessment (ERAA) for the Republic of Moldova. This assessment will be conducted primarily via the Low Emissions Analysis Platform (LEAP), but will utilize external scripting. The ERAA uses an hourly resolution to ensure that electricity supply meets or exceeds demand. Demand, as well as generation potential (supply) is a function of temperature, time of year, and location. Because of this, we will utilize local hourly climatological data to accurately capture variation in electricity supply and demand. This repository downloads relevant weather data (temperature, solar irradiance, wind speeds) from ERA5 (5th generation ECMWF reanalysis) for Moldova, translating it into solar/wind power availability factors, as well as models hourly demand.
